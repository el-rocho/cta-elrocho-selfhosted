# Actualización a v1.6.1-beta.3

> [!IMPORTANT]
> Realiza una copia completa del directorio `data` antes de actualizar. No basta con copiar únicamente `cta_database.sqlite` mientras el contenedor está activo, porque SQLite puede mantener cambios en archivos WAL auxiliares.

## Copia previa obligatoria

Desde el directorio de la instalación:

```bash
sudo docker compose down
sudo cp -a ./data "../control-tension-data-backup-$(date +%Y%m%d-%H%M%S)"
```

Guarda la copia fuera del directorio `data` y consérvala hasta terminar las comprobaciones.

## Migración de esta versión

Al arrancar, el servidor añade automáticamente la preferencia de visualización de etiquetas y avisos informativos. No se requiere ejecutar ningún comando SQL ni volver a configurar usuarios:

- Los usuarios existentes conservan visibles las etiquetas y avisos que ya utilizaban.
- Los usuarios creados después de la actualización comienzan con «Sin etiquetas ni avisos».
- Los avisos críticos de seguridad continúan activos en ambos casos.

## Actualizar y comprobar

```bash
git pull --ff-only
sudo docker compose pull
sudo docker compose up -d
sudo docker logs --tail 100 control-tension-server
```

Después, comprueba el inicio de sesión, el historial, la configuración de un usuario existente y la creación de un informe PDF o CSV. No elimines la copia previa hasta confirmar que todo funciona correctamente.
